Dashboard Analytique

Catégorie Data Visualization
Année 2024
Statut Complété

Un dashboard interactif proposant graphiques et visualisations de données en temps réel. Ce projet montre ma maîtrise des technologies de visualization et de traitement de données.

Le dashboard offre une interface intuitive permettant aux utilisateurs de surveiller les métriques clés, générer des rapports et prendre des décisions éclairées basées sur les données.

Technologies utilisées

React Chart.js Node.js PostgreSQL D3.js
